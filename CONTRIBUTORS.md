# Участники и использование ИИ

| Участник | Вклад |
| --- | --- |
| **d11zy** | Идея проекта, требования, выбор поведения приложения и проверка на своей системе Arch Linux + Hyprland. |
| **OpenAI Codex** | ИИ-инструмент, с помощью которого написана и доработана большая часть кода, интерфейса, тестов, сборки и документации. |

WayLookup разрабатывается d11zy с существенной помощью OpenAI Codex. Этот репозиторий не выдаётся за проект, полностью написанный человеком вручную. Codex указан как использованный ИИ-инструмент, а не как человек или отдельный сопровождающий проекта.

Этот файл описывает вклад явно. Автоматический блок **Contributors** в интерфейсе GitHub формируется по истории коммитов и связанным с ними аккаунтам; это не полный перечень использованных инструментов.
