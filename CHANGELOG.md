# История изменений

## 0.1.1

- Структурированная карточка с группировкой значений по источникам.
- Отдельные блоки перевода предложения и оригинала с подсветкой выбранного слова.
- Ограниченные размеры карточки, перенос длинных слов и раскрытие больших статей.
- Очистка форматирования и удаление повторов значений при отображении.
- Состояния загрузки и ошибок, повтор запроса, обработка некорректного ответа MyMemory.
- README с установкой пакета и скачиванием исходников, материалы первого публичного релиза.

## 0.1.0

- Python-демон с GTK3, AppIndicator tray и Wayland layer-shell.
- Захват сфокусированного монитора через grim, локальный Tesseract OCR.
- Клик по слову, восстановление предложения, перевод через MyMemory/LibreTranslate/Ollama.
- Импорт JSON и StarDict с несколькими значениями и синонимами.
- Настраиваемый Alt+Q, поддержка Lua/Hyprlang, выход по Esc.
- UTF-8 словарь для запоминания, настройки, CLI и диагностика.
- Arch PKGBUILD, desktop entry, user unit и проверки GitHub Actions.
