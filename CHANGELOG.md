# История изменений

## 0.2.0b1 — ветка `v0.2-beta`

Бета-версия: визуал и точность выделения. Основана на ветке `perf-faster-ocr`.

- Фразы: клик по слову сам находит устойчивое выражение из словаря рядом с ним
  (например, *by the way*). Повторный клик по слову фразы переводит только его,
  Shift/Ctrl+клик — всегда одно слово. Протяните мышью по словам, чтобы выделить
  свою фразу (до 8 слов одного абзаца); если её нет в словаре, она переводится
  как короткое предложение.
- Разорванные слова: склейка учитывает обычный пробел в строке. «some»+«thing»
  склеиваются, только если зазор заметно уже пробела; вплотную стоящие куски
  незнакомых слов (имена, термины) тоже объединяются.
- Разные шрифты и размеры: второй, «разреженный» проход OCR теперь всегда идёт в
  фоне после первых рамок и увеличивает мелкий текст до 2×, поэтому находит
  заголовки, подписи и мелкие надписи.
- Карточка перевода появляется рядом со словом: снизу, если не помещается — сверху,
  затем справа или слева; у края экрана она сдвигается внутрь. Сторона не прыгает,
  пока карточка помещается.
- Новая палитра: графитовая карточка, мягкий синий акцент `#8AB4FF`, янтарное
  выделение `#FFC857`; рамки слов скруглены, фраза подсвечивается одной плашкой.
- Анимации: карточка плавно проявляется и сдвигается (~170 мс), найденные слова
  проявляются, подсветка при наведении меняется плавно. Клик мимо слов скрывает
  карточку.

- Исправления беты: Esc и крестик закрывают только карточку (второй Esc — весь оверлей);
  карточка больше не уходит в случайное место — размер мерился вместе с отступами, которыми
  она позиционируется; сторона выбирается сразу под полную карточку. Дубликаты слов из
  второго прохода OCR со сдвинутой рамкой отбрасываются.

## Ветка `main`

- Прозрачный оверлей поверх живого экрана. **F2** переключает на стоп-кадр.
- Рамки основного прохода OCR появляются, пока дополнительный проход ищет пропущенные слова. Сочетание GNOME обращается к запущенному WayLookup через D-Bus.
- Близкие фрагменты английского слова могут объединяться по локальному словарю. Объединённое слово используется для клика и восстановления предложения.

## 0.1.1

- Структурированная карточка с группировкой значений по источникам.
- Отдельные блоки перевода предложения и оригинала с подсветкой выбранного слова.
- Ограниченные размеры карточки, перенос длинных слов и раскрытие больших статей.
- Очистка форматирования и удаление повторов значений при отображении.
- Состояния загрузки и ошибок, повтор запроса, обработка некорректного ответа MyMemory.
- README с установкой пакета и скачиванием исходников, материалы первого публичного релиза.

## 0.1.0

- Python-демон с GTK3, AppIndicator tray и Wayland layer-shell.
- Захват сфокусированного монитора через grim, локальный Tesseract OCR.
- Клик по слову, восстановление предложения, перевод через MyMemory/LibreTranslate/Ollama.
- Импорт JSON и StarDict с несколькими значениями и синонимами.
- Настраиваемый Alt+Q, поддержка Lua/Hyprlang, выход по Esc.
- UTF-8 словарь для запоминания, настройки, CLI и диагностика.
- Arch PKGBUILD, desktop entry, user unit и проверки GitHub Actions.
