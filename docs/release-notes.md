## WayLookup 0.1.1 — первое публичное издание

Перевод слов и предложений поверх игр и приложений под **Arch Linux + Hyprland / Wayland**. Интерфейс на русском, код на Python, лицензия MIT.

### Возможности

- Демон с tray, настраиваемый Alt+Q, закрытие по Esc.
- Локальный OCR Tesseract, кликабельные слова на снимке сфокусированного монитора.
- Структурированная карточка: значения по источникам, перевод предложения, оригинал с подсветкой слова.
- Офлайн-словари StarDict/JSON; MyMemory, LibreTranslate и Ollama.
- Несколько значений, раскрываемые длинные статьи, повтор неудачного запроса.
- Автоматический UTF-8 список слов с переводами и контекстом.

### Установка на Arch

Скачайте `waylookup-0.1.1-1-any.pkg.tar.zst` и `SHA256SUMS` из Assets внизу страницы. В каталоге загрузки:

```bash
sha256sum --ignore-missing --check SHA256SUMS && sudo pacman -U ./waylookup-0.1.1-1-any.pkg.tar.zst
waylookup doctor
waylookup daemon
```

Нажмите **Alt+Q**, выберите слово, затем **Esc**, чтобы закрыть оверлей. Иконка требует tray-модуля в панели. По умолчанию MyMemory отправляет выбранное слово и предложение в интернет. Для офлайн-режима подключите словарь и отключите перевод предложений и fallback либо настройте локальную Ollama.

### Ограничения и проверка

Версия ранняя. Замораживается снимок, **сама игра может продолжать работать**. Захватывается один сфокусированный монитор. Проверено на Hyprland 0.57.0, 1920×1080; старые Hyprlang-бинды, смешанные DPI, HDR, Gamescope и другие композиторы не проходили живую проверку. Качество OCR зависит от шрифта и контраста. ИИ требует отдельной установленной модели Ollama.

Проверены 19 тестов ядра и форматирования, живой GTK-оверлей, длинные статьи, состояния ошибок/загрузки, сохранение слов и устаревшие ответы. Импорт настоящего FreeDict English–Russian проверен на 62 181 статье. Полная инструкция — в README репозитория.
