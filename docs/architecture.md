# Устройство и ограничения

## Поток работы

1. `Gtk.Application` регистрирует экземпляр в session D-Bus и остаётся запущенным без окон. AppIndicator публикует tray-меню.
2. При старте приложение проверяет конфликт сочетания, добавляет временный бинд и слушает `configreloaded` через socket2 Hyprland. На Hyprland 0.55+ используется `hl.bind` через `hyprctl eval`, удаление — через собственный handle, а не удаление всех действий пользователя. В старых версиях используется `bindd`.
3. По бинду отдельный вызов CLI передаёт `capture` основному процессу. `hyprctl -j monitors` выбирает сфокусированный монитор, `grim -o OUTPUT -t png -` возвращает PNG в память до появления оверлея.
4. GTK Layer Shell создаёт поверхность уровня overlay на этом мониторе с клавиатурным фокусом. Она показывает снимок, поэтому содержимое визуально не меняется. Отдельный рабочий поток запускает Tesseract TSV. Границы распознаются в пикселях снимка и преобразуются при отрисовке и hit-test с учётом фактического размера GTK-поверхности.
5. Слова выделяются прямоугольниками. Клик выбирает самое маленькое пересекающееся слово; предложение восстанавливается по OCR-блоку/абзацу, порядку слов и пунктуации, включая переносы строк и несколько распространённых сокращений.
6. Отдельный пул перевода ищет словарные значения, показывает их, затем получает перевод предложения и пишет результат в UTF-8 файл. GTK обновляется только через `GLib.idle_add`. Номера сессии/выбора отбрасывают устаревшие ответы; сетевые вызовы не блокируют захват и Esc.
7. Esc уничтожает layer surface и возвращает фокус композитору. Повторный бинд закрывает открытый оверлей. При выходе демон снимает свой бинд.

## Модули

| Файл | Назначение |
| --- | --- |
| `config.py` | XDG-пути, валидация и атомарная запись JSON |
| `hyprland.py` | grim, hyprctl, динамические бинды, события перезагрузки |
| `ocr.py` | Tesseract, TSV, слова, координаты и предложения |
| `dictionary.py` | Транзакционный импорт JSON/StarDict, SQLite-поиск |
| `translation.py` | MyMemory / LibreTranslate / Ollama, обработка ошибок и кэш |
| `history.py` | Блокировка, дедупликация и запись слов в текст |
| `ui.py` | Демон, tray, GTK Layer Shell, оверлей и настройки |
| `card.py` | Карточка: группы значений, перевод, оригинал, загрузка, ошибки и повтор запроса |

| `cli.py` | Команды, диагностика и запуск GUI |

## Практические границы версии 0.1

- **Снимок замораживает изображение, а не игровой процесс.** Сетевые игры продолжаются; локальная игра иногда сама ставится на паузу при потере фокуса, но это зависит от игры. Автоматический SIGSTOP не применяется. При необходимости поставьте игру на паузу её средствами перед биндом.
- Покрывается один сфокусированный монитор. Другие мониторы остаются живыми. Расчёт масштабирования использует размеры реального снимка и логическую геометрию GTK; смешанный fractional scaling, повёрнутые и несколько мониторов пока не проходили живую проверку.
- Это обычная программа для пользовательской сессии, без root, доступа к `/dev/input` и перехвата всех клавиш. Сессия блокировки может скрывать оверлей и запрещать захват. Бинд не назначается работающим на заблокированном экране.
- Клавиатурный фокус слой забирает на время перевода. Горячие клавиши самого композитора могут продолжать работать. Если игра использует input inhibitor, бинд может не прийти; pause/menu или оконный режим могут помочь. Поведение конкретной игры, Gamescope и HDR ещё нужно проверять отдельно.
- Stylized fonts, мелкий текст, прозрачные субтитры, низкий контраст и анимация снижают качество Tesseract. Если OCR разбил предложение на разные блоки или абзацы, контекст может оказаться неполным. Не объединяем произвольно соседние элементы интерфейса. Снижение порога уверенности добавляет и полезный текст, и шум.
- Это не непрерывный видеоперевод: один захват по команде, затем выбор слов. Никаких моделей, словарей или облачных ключей приложение самостоятельно не скачивает.
- Поддержан поиск точной словоформы и StarDict `.syn`, без универсальной лемматизации. Отдельные значения внутри единой StarDict-статьи отображаются как текст статьи; раздельные JSON-значения — отдельными пунктами. Типы StarDict `m,l,g,t,x,y,k,w,h` поддержаны как текст, HTML/XML очищается; бинарные поля без sametypesequence пропускаются.
- Качество словаря, переводчика и ИИ разное. ИИ может ошибаться. Название источника показывается рядом с результатом. Ollama протестирован контрактными тестами HTTP-ответов, не живой моделью.
- Сетевые операции имеют таймаут, Tesseract — 60 секунд. Закрытие оверлея немедленное; выполняющийся запрос может закончить запись истории после закрытия. При завершении процесса Python дожидается уже начатых рабочих потоков до их таймаута; новые задачи отменяются.
- При аварийном `kill -9` cleanup не выполнится. Если временный бинд остался, перезагрузите конфигурацию Hyprland. Совместимость Lua/Hyprlang зависит от API композитора; для неподдержанной версии доступна ручная настройка команды capture.
- Tray требует StatusNotifier host (Waybar/Quickshell и т. п.). Доступность библиотеки AppIndicator не гарантирует, что панель показывает иконку. Управление через CLI остаётся доступным.
- Дедупликация истории читает существующий `.txt`; для очень больших многолетних файлов это может замедлить запись. SQLite используется только для словарей, не как скрытая замена пользовательского файла.

## Приватность

PNG хранится в памяти, Tesseract получает его через stdin. Скриншот не отправляется ни одному провайдеру и не сохраняется обычным режимом приложения. В сеть уходит только выбранное слово (при машинном/ИИ-переводе) и предложение (если провайдер включён). Адреса LibreTranslate/Ollama задаёт пользователь; локальный адрес по умолчанию не гарантирует локальность после его изменения. API-ключ LibreTranslate читается из окружения. Отдельные plaintext API-ключи в URL и конфиге не используются.

История и словарная база лежат в XDG data directory. Новый файл истории создаётся с режимом 0600; существующий выбранный пользователем файл сохраняет его права. Не коммитьте пользовательские словари без проверки лицензий и личные файлы слов. Сгенерированный preview в репозитории содержит только синтетическую сцену.
